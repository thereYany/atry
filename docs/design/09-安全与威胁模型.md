# 09 安全与威胁模型

> 目标：生产级框架必须回答"会被怎么打、泄露什么、怎么证明防住了"。本文覆盖资产、信任边界、威胁清单、缓解与验证；不追求成为合规白皮书。

## 1. 资产与敏感级别

| 资产 | 位置 | 敏感级别 | 泄露影响 |
|---|---|---|---|
| API Key 明文 | 仅创建时返回一次；客户端持有 | 高 | 盗用调用、产生费用、数据泄露 |
| API Key 哈希/前缀 | identity DB | 中 | 暴力破解风险低，但需防枚举 |
| Provider 凭证（API key/证书） | 外部密钥引用（env/KMS） | 最高 | 直接盗刷、封号 |
| 调用内容（prompt/response） | 内存/对象存储（可选） | 高（可能含 PII/商业机密） | 隐私/合规事故 |
| 用量事件/账单/余额/账本 | metering DB | 高（资金相关） | 计费纠纷、财务损失 |
| 调用记录/日志/trace | 日志系统 | 中高（含元数据，可能含内容） | 行为画像、内部信息泄露 |
| 配置（路由/价格/限额） | 配置中心/DB | 中 | 被篡改导致成本/可用性事故 |

## 2. 信任边界

```text
[不可信] 客户端/第三方  ──HTTPS──►  [边界1] API 网关/接入层（TLS、鉴权、限流）
                                        │
                                        ▼
                                  [边界2] atry llm 模块（业务可信，输入不可信）
                                   │                     │
                          [边界3] provider 外网          [边界4] metering 内部
                          （TLS、响应不可信）             （DB/账本，高保护）
                                        │
                                        ▼
                                  [边界5] 观测系统（日志/trace/metric，需脱敏/访问控制）
[边界6] 运营/管理端 ──RBAC/审计──► 配置/价格/额度/账单
```

规则：

- 跨边界一律"输入不可信"：客户端请求、上游 LLM 响应、provider 错误体、webhook（未来）、配置导入。
- 内容（prompt/response）默认不落日志/DB；需要审计时写受控对象存储，日志仅引用。
- metering 的账本/余额只允许本模块内部写；管理端通过契约 + 审计，不直接改表。

## 3. 威胁清单（STRIDE 风格）

| ID | 威胁 | 场景 | 缓解 | 验证 |
|---|---|---|---|---|
| T1 | API Key 泄露/盗用 | 日志打印、错误信息回显、前端缓存、共享密钥 | 只存哈希；日志/异常脱敏；key 前缀标识；支持吊销/轮换；按租户/额度限制；异常调用告警 | 日志扫描用例、泄露演练、吊销生效测试 |
| T2 | Provider 凭证泄露 | 配置明文、异常堆栈、管理端返回 | 只允许 `env:`/`kms:` 引用；配置打印脱敏；管理端只显示指纹；启动校验 | 配置泄露扫描、启动失败测试 |
| T3 | SSRF/恶意 endpoint | 用户或配置把 base-url 指向内网/元数据服务 | endpoint 白名单/域名 allowlist；禁止用户请求覆盖 provider 地址；出站代理限制；TLS 校验开启 | SSRF 用例（内网地址/重定向） |
| T4 | 越权/租户穿透 | 查询/账单/调用拿到他人数据 | tenant_id 强制过滤（复用租户规范）；契约层 SubjectRef；跨租户管理仅运营端；测试矩阵 | 跨租户测试、SQL 检查 |
| T5 | 重放/重复扣费 | 客户端重试、网络重放 | requestId 幂等；API Idempotency-Key；reservation 终态唯一；事件唯一键 | 重放测试（同 requestId N 次只计一次） |
| T6 | 盗刷/Denial of Wallet | 密钥被盗后狂刷、低成本模型绕过预算 | 多维限流 + 日预算 + max_tokens 上限 + 租户配额 + 成本告警 + 异常速率熔断 | 预算绕过测试、限流测试、成本告警演练 |
| T7 | 日志注入/敏感泄露 | 用户内容含换行/控制字符/密钥，污染日志或泄露 PII | 结构化 JSON + 控制字符转义；内容默认不落；`@Sensitive` 脱敏；日志访问控制与保留 | 注入测试、日志扫描 |
| T8 | 计费篡改/账实不符 | 直接改余额、重复入账、改历史账单 | 账本不可变；余额由流水派生；价格版本快照；finalize 后不可改；管理操作审计；对账 | 不变量测试、对账演练、审计测试 |
| T9 | 管理端提权 | 普通用户调用管理接口；API Key 访问运营端 | RBAC + scope 分离；管理端独立鉴权；操作审计；最小权限 | 权限矩阵测试 |
| T10 | 数据存储被拖库 | DB/Redis 弱口令、备份泄露 | 最小权限账号、网络隔离、加密/脱敏、备份加密；Redis 不存敏感明文 | 配置审计、扫描 |
| T11 | 供应链/依赖漏洞 | SDK/依赖带漏洞、动态加载 | 锁定版本、依赖扫描、SBOM；不动态执行模型输出；供应商评估 | CI 依赖扫描 |
| T12 | 模型输出被当作可信指令 | 下游直接执行/拼接 SQL/命令 | 输出视为不可信：schema/协议校验、禁止直接执行、工具调用白名单与人工确认；hooks 留给使用方 | 输出注入测试（框架只保证不放大信任） |
| T13 | 内容合规/PII | 调用内容含个人数据、未授权留存 | 默认不落内容；留存需策略与加密；访问审计；可配置脱敏钩子；数据保留期 | 数据流审计、留存检查 |
| T14 | 配置篡改 | 价格/路由被改成 0 价/指向恶意 provider | 配置变更 RBAC + 审计 + 审批；配置校验（价格>0、endpoint 白名单）；版本化可回滚 | 配置变更审计、非法配置拒绝 |
| T15 | 计时/配额绕过 | 并发请求绕过内存预扣、多实例不一致 | 预扣持久化 + 原子 CAS；多实例 Redis/DB 计数；对账补偿；配额按租户原子扣减 | 并发超卖测试、多实例模拟 |

## 4. 控制措施（按层）

| 层 | 控制 |
|---|---|
| 接入 | TLS 终止、鉴权（API Key/JWT）、限流、请求大小上限、超时、WAF/网关（部署层） |
| 认证与授权 | API Key 只存哈希、scope/租户绑定、RBAC（管理端）、密钥轮换与吊销 |
| 调用 | SSRF 防护（endpoint allowlist）、出站 TLS 校验、请求内容大小上限、max_tokens 上限 |
| 计费 | 幂等键、预扣/结算状态机、不可变账本、价格版本、对账、预算告警 |
| 日志/观测 | 结构化日志、默认无内容、脱敏（密钥/PII）、采样、访问控制、保留期 |
| 数据 | 最小权限、加密（传输/静态）、备份加密、审计、租户隔离 |
| 运营 | 配置审批/审计、变更可回滚、双人复核（价格/额度）、应急吊销 |

## 5. 安全测试（进入 06 测试矩阵）

1. 日志/错误响应扫描：密钥、Authorization、cookie、prompt/response 明文绝不出现。
2. 鉴权矩阵：无 key/错误 key/吊销 key/越权 scope/跨租户 → 401/403，且不产生计费。
3. SSRF：base-url 指向 localhost/内网/云元数据/重定向 → 拒绝/白名单校验。
4. 重放：同 requestId/Idempotency-Key 多次 → 只计费一次；并发重复 → 409/幂等结果。
5. 盗刷：超限速、超预算、超 max_tokens、异常租户 → 429/402/降级，成本告警触发。
6. 计费篡改：直接调用管理接口改余额/改历史账单 → 拒绝；审计留痕。
7. 日志注入：内容含换行/ANSI/JSON 破坏字符 → 日志仍为合法 JSON、无字段注入。
8. 配置安全：价格=0/负数、endpoint 非法、密钥明文 → 启动/保存失败。
9. 多实例并发：预扣/配额跨实例不超卖（用 Redis/DB 计数模拟）。
10. 依赖扫描：CI 中 OWASP dependency-check/SCA（可选，至少人工审新依赖）。

## 6. 残余风险与边界

- 框架无法阻止业务方把 LLM 输出直接拼 SQL/命令；提供 hooks 与文档约束，不宣称解决提示注入。
- 无法防止合法密钥持有者滥用（只能限额、告警、封禁）。
- 内容合规（PII/敏感信息）依赖使用方策略与留存配置，框架提供默认关闭内容落盘与脱敏钩子。
- 真实支付/充值系统的 PCI/资金合规不在本期范围。
- 多租户强隔离依赖 atry 租户规范与 DB 权限；若未来引入跨库/跨服务，需要重新评估信任边界。

## 7. 安全评审清单

- [ ] 密钥/凭证：只存引用/哈希，日志与异常无明文
- [ ] 输入：大小、类型、endpoint、参数上限校验
- [ ] 输出：上游响应视为不可信，schema 校验，不直接执行
- [ ] 租户：所有查询/写入带 tenant 约束，跨租户测试通过
- [ ] 计费：幂等、不可变账本、对账、管理操作审计
- [ ] 观测：内容默认不落、脱敏、采样、访问控制
- [ ] 配置：变更审计、校验、可回滚
- [ ] 依赖：版本锁定、漏洞扫描、SBOM（至少记录）
- [ ] 应急：吊销/封禁/回滚/降级预案
